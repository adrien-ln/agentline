# agentline: notes for coding agents and contributors

The Claude Code statusline and its theme picker, in Go (binary `agentline`, module `github.com/adrien-ln/agentline`; it was called `sl`, project `statusline`, before the rename). The README says how to install and use the tool (keep it short: requirements and install first), [ROADMAP.md](ROADMAP.md) what is left, [docs/HISTORY.md](docs/HISTORY.md) how and why it moved from bash to Go, [CONTRIBUTING.md](CONTRIBUTING.md) how to contribute.

## Commands

```bash
gofmt -l . ; go vet ./... && go test ./...            # before every commit (the CI does the same, plus govulncheck)
go run golang.org/x/vuln/cmd/govulncheck@latest ./...
go test ./internal/render -maj                         # rewrites tests/golden/: only for an INTENDED rendering change, then read the diff
go run ./cmd/agentline install                         # installs on this machine for real (see Pitfalls)
vhs docs/demo/demo.tape && vhs docs/demo/statusline.tape   # regenerates the README GIF and image
```

## Project rules

- **Rendering identical to the old bash version**, byte for byte: the references in `tests/golden/` (30 cases, plus 3 cases per theme in `themes/`), at truecolor level on a dark background (the default), in French (the `TestMain` of `internal/render` forces `fr`). A change that alters a reference unintentionally is a regression. Other levels and the light background have their own references, produced by Go and reviewed: `tests/golden/256/`, `16/`, `none/` (`TestReferencesNiveaux`) and `clair/` (`TestReferencesClair`), in French too; English has its own in `tests/golden/en/` (13, 2 of them on a light background: `TestReferencesAnglaises`).
- **Languages**: English by default, French kept. Every new visible string goes through the catalog (`i18n.T("texte français")`, with its translation in `internal/i18n/catalogue_*.go`); `TestTextesDuCode` rejects a marked text missing from the catalog, an unused entry or mismatched `%` verbs. Package tests check French (`TestMain` in `langue_test.go`) and have one test in English. Code and comments stay in French.
- **Public interface in English**: options (`--in-place`, `--no-font`, `--font`), `help` subcommand, style keys and values (`model.name`, `ctx.label`, `yes`/`no`…), environment variables, theme variables and headers. The old French names are still read (`style/anciens.go`, `theme.Lire`, `Entete`, `variables.go`), never written; the built-in themes keep their French names.
- **Colors**: no color sequence outside `internal/ansi` (`grep '38;2\|48;2'` only finds it). Rendering goes through `Env.Couleurs` (`ansi.Profil`); the picker colors in 24 bits and `View` brings everything down to the level with `Profil.Adapter`. Level: `AGENTLINE_COLORS` > `NO_COLOR` > detection (`TERM=dumb`, `COLORTERM`, `WT_SESSION`, `TERM_PROGRAM`, `TERM`) > truecolor. On the short SSH line: forced level > `AGENTLINE_SSH_RICH` (24 bits) > fixed ANSI colors (`niveauCouleurs` in `main.go`). Without color, bold and italic stay (no-color.org).
- **Background**: `AGENTLINE_BACKGROUND` (dark, light; auto ignores the setting) > `$AGENTLINE_CONFIG/fond` > `COLORFGBG` > dark. The statusline never queries the terminal; only the picker, `install`, `theme background` and `doctor` send OSC 11 (`detecterFond`, replaced in the `TestMain` of `cmd/agentline`). A theme on the other background: `_CLAIR`/`_SOMBRE` colors, otherwise `PourFond` (WCAG contrast per role against `ansi.FondClair`/`FondSombre`, hue kept).
- **Style**: without a `style` file, or with every default value written out, rendering stays that of the references (`TestReferencesStyleToutDefaut`). A new option goes into `style.Cles()` (read by the CLI, the picker and validation), with its test in `internal/render/style_test.go`.
- **Theme priority**: `AGENTLINE_THEME` > branch > project > default > `AGENTLINE_PALETTE` > `tokyo`. A project is recognized by the normalized URL of its remote, otherwise by its path.
- **Variables**: `AGENTLINE_CONFIG`, `_THEME`, `_STYLE`, `_PALETTE`, `_SSH_RICH`, `_COLORS`, `_BACKGROUND`, `_NOW`, `_GIT_TIMEOUT`, `_PS_PROFILE`, `_LANG` (listed in `variables.go`, except `_LANG`, read by `i18n.Detecter`). The code always reads the new name through the `getenv` of `cmd/agentline` (never `os.Getenv`): old names are only read as a fallback when the new one is unset (`AGENTLINE_SSH_RICHE` and `AGENTLINE_PROFIL_PS`, the French names, then `SL_*`).
- **Theme tags**: `populaire` and dominant colors only (rouge, orange, jaune, vert, cyan, bleu, violet, rose, gris), no shades. `internal/theme/theme_test.go` rejects others. The picker's "light" filter comes from `# fond: clair`, not from a tag. English tags (`popular`, `red`…) are read under their French name.
- **Tests**: no hard-coded numbers that break when a theme is added or removed (thresholds, `m.lignesListe`, computations from `m.noms`).
- **Deterministic animations**: everything depends on `m.t` (ms); tests fix the instant (`eveille`, `instantOu`).
- **Picker**: `View` does not modify state (except caches); the layout is recomputed by `ajuster` on every key and resize. A new key goes into the table of `touches.go`, which also builds the footer and the help.
- **Widths**: the picker measures in columns (`largeur`, go-runewidth); rendering keeps measuring in characters (`ansi.Visible`), like the references.
- **Pip**, the agentline mascot, is an original drawing in pixels (18 × 6: 3 lines × 9 columns of half blocks, two colors at most per cell, checked by `TestDemiLigne`), the body in the theme colors, the beak and legs in `D75` (`D100` when `D75` blends into the body, `couleurBec`). Its parts (wings, eyes, legs, profiles for the turn) are at the top of `mascotte.go`. It replaced Clawd, whose drawing belongs to Anthropic.
- **No new Go dependency** without discussion; they are pinned in `go.sum`. Direct: bubbletea, go-runewidth, golang.org/x/sys (already pulled by bubbletea, for the Windows registry).
- **Installation has no real effect in tests**: everything that touches the system goes through `installation.Options` (`Getenv`, `Lancer`, `Registre`, `Diffuser`, `Chercher`, `Telecharger`, `Demander`); nil means "nothing is read or run". Only `cmd/agentline/installation.go` (`optionsReelles`) wires the real system. Tests simulate windows, darwin and linux (`simuler` in `systeme_test.go`) on any machine. The `TestMain` of `cmd/agentline` points `AGENTLINE_CONFIG`, `XDG_CONFIG_HOME` and `HOME` to a temporary folder.
- **Installation: nothing without a copy or consent**: every configuration file changed gets a dated `.bak` copy (the old HKCU PATH too, in `~/bin/path-utilisateur.*.bak`); leftovers of `sl` are renamed to `.bak`, never deleted, and only when recognized as coming from `sl`; the font is installed only after a yes, or when named (`--font`, `agentline font set`: a terminal still confirms before the download); `agentline uninstall` only removes from the HKCU PATH what the installation put there (marker `~/bin/.agentline-path`, or the old `.sl-path`).

## Pitfalls

- **Escapes**: `sed` and `perl` have already inserted a raw ESC byte into a Go regex, and `\n` or `\t` passed through the shell have become real newlines (`sed 's/…/"\\x1b[…"/'` writes a raw ESC, and so does `printf`). To change code, prefer an editing tool. Check that no source file contains an ESC byte: `grep -l $'\x1b' $(git ls-files '*.go')` must print nothing.
- **`SSH_CONNECTION`** switches the statusline to one short line only with `ssh.short=yes` in the style (`ligneCourte` in `main.go`; off by default: the full statusline everywhere). A session started over SSH passes it to vhs and manual tests: the `.tape` scripts unset it.
- **Real settings**: `agentline theme set`, `link`, `branch` (and the picker) write to `~/.config/agentline/`, and the first access copies `~/.config/statusline/` there. Every manual test uses `AGENTLINE_CONFIG` pointing to a temporary folder (`AGENTLINE_CONFIG=$(mktemp -d) agentline theme set nord`); an agent once overwrote a real default theme.
- **Never run `agentline install` or `agentline uninstall` to try something**: they write to the registry (HKCU PATH), `~/.claude/settings.json`, shell files, rename the old `sl`, clean the PowerShell profile and, after a yes, install a font and change Windows Terminal and VS Code. Test through the simulations of `internal/installation`; `agentline doctor` changes nothing (except the one-time copy of old settings, done by any first access).
- **Shell shortcuts**: a `$'\x1b'` or a `$(…)` in a command may be refused by agent sandboxes; search for the ESC byte with the search tool (pattern `\x1b`). Invisible characters (BOM) written by an editing tool land raw in the file: write them as bytes (`"\xef\xbb\xbf"`).
- **vhs** captures nothing during `Hide`. `Screenshot` needs a `Show` right before and a pause right after.

## Git

Commit messages in English, strict Conventional Commits: `type(scope): imperative summary`, lowercase, 72 characters at most, no final period; an optional body explains why, lines of 72 characters at most. Types: `feat`, `fix`, `perf`, `refactor`, `test`, `docs`, `chore`, `ci`, `build`, `revert`. Scopes: `render`, `selector`, `style`, `theme`, `install`, `cli`, `i18n`, `colors`, `docs`, `ci`, `deps` (or none for general docs). `bash scripts/verifier-commits.sh main..HEAD` checks them, as the CI does on every pull request. No attribution trailer. One branch per task, fast-forward merge into `main` (no merge commit). No push without being asked.
